# BARRAS — El juego de Noa

Juego web de rap: completa la barra que rima, mide tu flow, reta en duelos, escribe tu canción con portada de álbum, juega al quiz y colecciona cartas.

**Jugar:** https://magodago.github.io/noa-barras/

## Contenido
- `index.html` — entrada
- `main.js` — juego completo (React empaquetado, datos de barras y quiz incluidos)
- `main.css` — estilos

Sin dependencias externas ni backend: es estático puro. Funciona abierto desde un servidor local (`python3 -m http.server`) porque usa módulos ES.

Publicado con GitHub Pages desde la rama `main`, raíz del repositorio.
